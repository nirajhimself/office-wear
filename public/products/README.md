Product photography goes here.

Drop a file in this folder and reference it from the admin product form as
`/products/<filename>`, e.g. `/products/oxford-shirt-front.jpg`.

Local paths need no entry in `images.remotePatterns` in next.config.ts.
Photos served from a CDN do: set `IMAGE_HOSTS` in .env to a comma-separated
list of hostnames.

Shoot or export at roughly 1200×1600 (3:4 portrait) to match the product cards.
